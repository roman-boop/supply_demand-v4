# Supply / Demand бот для Telegram

**Связь с автором:** [telegram](https://t.me/Perpetual_god)  
**BingX со скидкой 25% на все комиссии (taker 0.0375%):** [ссылка](https://bingx.com/ru/partner/maniacdt)

Бот ищет зоны спроса и предложения на свечах BingX и отправляет сигнал с графиком в Telegram при первом возврате цены к зоне. Сделки он не открывает.

## Как работает поиск

- Зоны строятся по закрытым свечам 15m у локального минимума или максимума.
- Исходной служит последняя свеча противоположного направления перед импульсом либо свеча с длинным фитилём.
- Выход из зоны должен начаться на следующей свече и получить подтверждение в пределах четырёх свечей.
- Пробитые и уже посещённые зоны исключаются.
- Сигнал отправляется, когда закрытая свеча 5m касается зоны и образует пинбар.

Основные пороги и интервалы находятся в начале `v4.py`. Их можно изменить под свой набор инструментов, но это изменит состав сигналов.

## Запуск

Нужен Python 3.9 или новее. Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Задайте переменные окружения `BOT_TOKEN` и `CHAT_ID`. Например, в PowerShell:

```powershell
$env:BOT_TOKEN = "токен_бота"
$env:CHAT_ID = "номер_чата"
python v4.py
```

`BOT_TOKEN` выдаёт BotFather. `CHAT_ID` должен указывать на чат, в который бот может отправлять сообщения. Ключи BingX для чтения публичных свечей в этой версии не используются.

## Файлы

| Файл | Назначение |
| --- | --- |
| `v4.py` | Поиск зон, проверка сигнала, график и отправка в Telegram |
| `bingx_client.py` | Получение и разбор свечей BingX |
| `requirements.txt` | Зависимости Python |

Состояние уже отправленных сигналов хранится в памяти процесса. После перезапуска оно сбрасывается. Сканирование всех контрактов может занимать больше пяти минут: запросы свечей запускаются с интервалом 1,1 секунды, а пауза между обходами начинается после завершения предыдущего.
